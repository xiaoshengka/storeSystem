# v0.6.0

基线：v0.5.1。本版本已通过单元、Reactor、Cache、AOF 交叉恢复、benchmark
smoke、ASan/UBSan 和 Valgrind 验证，并完成 Redis 6.2.23 的 5 轮集合对照；190
轮对照请求均无客户端错误，预期与实际 cardinality 一致。性能数字依赖具体机器、
编译和负载环境，因此不固化在发布说明中。

主要变更：

- 顶层动态 Hash keyspace 的 value 改为 String/Hash/ZSet 类型对象。
- 新增 HSET/HGET/HDEL/HLEN/HGETALL。
- 新增 ZADD/ZREM/ZSCORE/ZCARD/ZRANGE，支持 SkipList 和 RBTree 后端。
- 新增 RESP2 Bulk Array 编码和 Reactor 1 MiB 可复用响应缓冲。
- AOF 支持集合写命令及 SkipList/RBTree 交叉恢复。
- INFO CACHE 增加各对象 key 数、field/member 数及当前 ZSet 后端。
- 新增同一 RESP2 C 客户端与 Python 编排脚本，用统一数据集对照本项目和 Redis
  6.2.23；Redis 对照关闭紧凑编码、RDB 和自动 AOF rewrite。

限制：不实现 Redis Set、成员级 TTL、ZADD 高级选项、AOF rewrite 或全局 keyspace
引擎切换。详细设计见
[`docs/typed-collections-v0.6.md`](../typed-collections-v0.6.md)。
